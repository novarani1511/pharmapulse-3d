Latar Belakang & Permasalahan

URGENSI PENELITIAN

Tantangan Desain Obat Klasik

Proses penemuan & formulasi obat tradisional membutuhkan waktu bertahun-tahun dan biaya tinggi. Banyak calon molekul obat gagal pada tahap pengujian klinis akibat sifat permeabilitas dan absorpsi oral yang buruk.

Peran Aturan Lipinski (RO5)

Christopher A. Lipinski merumuskan Aturan Empat Parameter (Lipinski's Rule of Five) untuk memprediksi secara cepat apakah suatu molekul obat memiliki permeabilitas membran sel dan sifat bioavailabilitas oral yang ideal.

Kebutuhan Akses Data Real-Time

Laboratorium akademis dan QC/R&D industri farmasi memerlukan alat bantu komputasi yang terhubung secara otomatis dengan basis data molekul ilmiah terpercaya tanpa perlu menginput parameter fisikokimia secara manual.

Pentingnya Spatial 3D Conformer

Pemahaman konformasi 3D molekul (panjang ikatan, gugus fungsi, dan kepolaran ruang) sangat vital dalam memprediksi interaksi obat dengan reseptor biologis target.

Solusi & Inovasi PharmaPulse 3D

INOVASI TEKNOLOGI

Integrasi PubChem API

Terhubung langsung dengan PubChem PUG-REST API (NIH/NLM) secara gratis dan tanpa API key, menarik 15+ deskriptor fisikokimia secara otomatis dalam hitungan milidetik.

Engine 3Dmol.js

Visualisator 3D konformer molekul interaktif yang dapat diputar 360°, di-zoom, dan diubah mode tampilannya (Ball & Stick, Spacefill, Wireframe) sesuai standar atom CPK.

Multi-QSAR Evaluator

Evaluasi otomatis Lipinski RO5, Veber Bioavailability Filter, Ghose Filter, Pfizer 3/75 Toxicity Risk, serta grafik radar polaritas molekul berbasis Chart.js.

Arsitektur Sistem & Alur Data

ALUR KERJA DATA
  • 1. Pencarian Input Pengguna: Pengguna memasukkan Nama Obat (misal: Paracetamol, Atorvastatin), SMILES, atau PubChem CID.
  • 2. Query PUG-REST PubChem API: Aplikasi melakukan kueri HTTP REST API untuk mendapatkan CID, deskriptor sifat fisikokimia, dan file koordinat 3D SDF.
  • 3. Pengolahan Komputasi QSAR & Lipinski: Algoritma mengevaluasi pelanggaran batas Lipinski (MW ≤ 500, LogP ≤ 5, HBD ≤ 5, HBA ≤ 10) & aturan pendukung.
  • 4. Rendering UI Dashboard & 3D Viewer: Menampilkan hasil evaluasi pada antarmuka modern Dark Glassmorphism beserta grafik radar dan viewer 3D.

Parameter Evaluasi Lipinski RO5 & QSAR

STANDAR EVALUASI

4 Aturan Lipinski (RO5)

  • Molecular Weight (MW): ≤ 500 g/mol
  • Partition Coefficient (LogP): ≤ 5
  • H-Bond Donors (HBD): ≤ 5 (gugus -OH, -NH)
  • H-Bond Acceptors (HBA): ≤ 10 (atom O, N)

Saringan Tambahan Bioavailabilitas

  • Veber Rule: RotB ≤ 10 & TPSA ≤ 140 Å²
  • Ghose Filter: MW (160-480), LogP (-0.4 s/d 5.6)
  • Pfizer 3/75 Rule: LogP > 3 & TPSA < 75 Å² (Risiko Toksisitas Tinggi)

Keandalan & Robustness System

FITUR ANDALAN

Tiered Property Fallback Query

Menangani variasi kunci properti PubChem (XLogP vs XLogP3) secara dinamis untuk mencegah error HTTP 400 Bad Request pada senyawa obat mana pun.

Offline Dataset Cache

Memiliki penampung data pra-cache lokal untuk 9+ senyawa obat preset utama, menjamin aplikasi tetap berjalan 100% lancar meski tanpa koneksi internet.
